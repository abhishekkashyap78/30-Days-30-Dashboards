## 📊 Project Overview

Welcome to **Day 18 of my 30 Days, 30 Dashboards Challenge**!

In this project, I created an interactive **Amazon E-Commerce Analysis Dashboard** using Microsoft Power BI.

The dashboard analyzes e-commerce data to understand sales performance, product performance, customer orders, revenue, categories, and overall business trends.

The objective is to transform raw e-commerce data into meaningful insights that can support data-driven business decisions.

---

## 🎯 Business Problem

E-commerce businesses generate large amounts of data related to orders, products, sales, customers, categories, and revenue.

Analyzing this data manually can make it difficult to identify important trends and performance patterns.

This dashboard was developed to answer questions such as:

- What is the overall sales performance?
- Which products generate the highest sales?
- Which categories perform the best?
- How are sales changing over time?
- Which products contribute the most to revenue?
- What are the major sales trends?
- How can businesses use data to improve decision-making?

## 🧩 Challenge Faced

One of the main challenges in this project was **cleaning and structuring the raw e-commerce dataset** before creating the dashboard.

The major challenges included:

- Handling missing values
- Removing duplicate records
- Standardizing product and category names
- Correcting data types
- Cleaning numerical fields
- Creating calculated measures
- Ensuring accurate KPI calculations

Power Query was used extensively to prepare the dataset before visualization.

## 🧹 Data Cleaning & Preparation

The raw Amazon e-commerce dataset was processed using Power Query.

### Data Preparation Steps

1. Imported the dataset into Power BI.
2. Reviewed the available columns.
3. Checked data types.
4. Removed duplicate records.
5. Handled missing values.
6. Standardized text fields.
7. Cleaned numerical columns.
8. Converted date fields.
9. Created required calculated columns.
10. Validated the cleaned dataset.
11. Loaded the final data into the Power BI model.
