## 📊 Project Overview

Welcome to **Day 17 of my 30 Days, 30 Dashboards Challenge**!

In this project, I created an interactive **YouTube Analytics Dashboard** using Microsoft Power BI.

The dashboard focuses on analyzing YouTube video and channel performance through different metrics such as:

- 👀 Views
- 👍 Likes
- 💬 Comments
- 📺 Videos
- 🎬 Categories
- 📈 Engagement
- 🏆 Top-performing content
- 📅 Performance trends

The goal was to transform raw YouTube data into meaningful visual insights that can help understand content performance and audience engagement.

---

## 🎯 Business Problem

YouTube generates a large amount of data related to videos, channels, views, likes, comments, categories, and engagement.

For content creators and businesses, it is important to understand:

- Which videos perform the best?
- Which categories generate more views?
- What type of content gets higher engagement?
- How are views changing over time?
- Which videos receive more likes and comments?
- Which content should be analyzed for future strategy?

This dashboard provides an interactive solution for exploring these questions.
