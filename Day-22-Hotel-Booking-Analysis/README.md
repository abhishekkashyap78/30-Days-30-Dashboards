## 📊 Project Overview

This project is part of my **30 Days, 30 Dashboards Challenge**.

For Day 22, I created an interactive **Hotel Booking Analysis Dashboard using Microsoft Power BI**.

The dashboard analyzes hotel bookings, cancellations, revenue, room demand, customer behavior, booking lead time, stay duration, and booking trends.

The objective is to transform raw hotel booking data into meaningful business insights that can support better operational and revenue decisions.

---

## 🎯 Business Problem

Hotels generate large amounts of data related to:

- Bookings
- Cancellations
- Revenue
- Guests
- Room types
- Stay duration
- Booking channels
- Customer segments
- Arrival dates

Without proper analysis, it can be difficult to understand booking patterns, identify cancellation trends, estimate room demand, and optimize hotel performance.

This dashboard provides an interactive solution for analyzing hotel booking performance.
