# Day 9 - Social Media Analytics Dashboard

## 📊 Overview
An interactive Power BI dashboard designed to analyze social media
performance, audience engagement, content reach, and platform trends.

## 🎯 Business Problem
Businesses need to understand which platforms and content types generate
the highest engagement and reach in order to improve their social media strategy.

## 💡 Key Insights
- Analyzed followers and audience growth
- Compared likes, comments, and shares
- Analyzed overall engagement
- Compared platform performance
- Identified high-performing content
- Analyzed content reach and engagement trends

## 🚀 Business Action
These insights can help businesses optimize their content strategy,
improve audience engagement, and focus marketing efforts on
high-performing platforms and content.

## 🛠️ Tools Used
- Power BI
- Power Query
- DAX
- Data Visualization
