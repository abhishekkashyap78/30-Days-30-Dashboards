## 📊 Project Overview

This project is part of my **30 Days, 30 Dashboards Challenge**.

For Day 24, I created an interactive **Football Performance Dashboard using Microsoft Power BI**.

The dashboard analyzes football teams, players, matches, goals, wins, losses, draws, points, and overall performance to generate meaningful sports analytics insights.

---

## 🎯 Business Problem

Football generates a large amount of performance data related to:

- Matches
- Teams
- Players
- Goals
- Wins
- Losses
- Draws
- Points
- Player performance
- Match results

Without proper analysis, it can be difficult to understand team performance, identify top players, compare teams, and analyze match trends.

This dashboard converts football data into interactive and easy-to-understand visual insights.

---

## 🚀 Project Objectives

The main objectives of this dashboard are:

- Analyze overall football performance
- Compare team performance
- Analyze match results
- Track wins, losses, and draws
- Analyze goals scored
- Identify top-performing players
- Compare player performance
- Analyze points and rankings
- Study match trends
- Identify high-performing teams
