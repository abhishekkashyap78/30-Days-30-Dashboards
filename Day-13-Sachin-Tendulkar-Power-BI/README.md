## 📌 Project Overview

This project is **Day 13 of my 30 Days, 30 Dashboards Challenge**.

For Day 13, I created an interactive **Sachin Tendulkar Cricket Analytics Dashboard using Microsoft Power BI**.

The purpose of this project is to analyze the career and batting performance of one of the greatest cricketers through data visualization and interactive analytics.

The dashboard provides insights into Sachin Tendulkar's performance across different formats, years, opponents, and major tournaments.

Instead of looking at cricket statistics through traditional tables, this project transforms the data into an interactive and visually engaging dashboard.

---

# 🎯 Project Objective

The main objective of this project was to analyze Sachin Tendulkar's cricket career and identify important performance patterns using Power BI.

The dashboard focuses on:

- 🏏 Career performance
- 📊 Runs scored
- 💯 Centuries
- 📈 Year-wise performance
- 🌍 Performance against opponents
- 🏆 World Cup performance
- 📅 Format-wise analysis
- 🔥 Career milestones
- 📊 Batting trends

Sachin Tendulkar had an extraordinary international cricket career spanning more than two decades.

His career statistics provide a large amount of data that can be analyzed from multiple perspectives.

This dashboard uses that data to understand:
