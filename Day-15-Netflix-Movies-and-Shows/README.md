## 📌 Project Overview

This project is **Day 15 of my 30 Days, 30 Dashboards Challenge**.

For Day 15, I created an interactive **Netflix Movies & Shows Analytics Dashboard using Microsoft Power BI**.

The objective of this project is to analyze Netflix's content library and understand different patterns related to movies and TV shows.

The dashboard transforms raw Netflix content data into meaningful visual insights by analyzing:

- Movies and TV Shows
- Genres
- Countries
- Release Years
- Ratings
- Content Distribution
- Movie Duration
- TV Show Seasons
- Content Growth Trends

The goal is to make a large entertainment dataset easier to explore through interactive data visualization.

# 🎬 Business Problem

Streaming platforms have large content libraries containing thousands of movies and TV shows.

Analyzing this data manually can make it difficult to understand:

- What type of content dominates the platform?
- Which countries contribute the most content?
- Which genres are most common?
- How has content changed over time?
- Which ratings are most frequently used?
- How are movies and TV shows distributed?
- What are the common movie durations?
- How many seasons do TV shows typically have?

This dashboard provides an interactive way to explore these questions.

# 🔍 Key Insights

The dashboard provides several useful insights into Netflix content.

### 1. Content Type

The dashboard provides a clear comparison between movies and TV shows, making it easier to understand the composition of the Netflix library.

### 2. Genre Distribution

Different genres contribute differently to the overall content library. Genre analysis helps identify dominant content categories.

### 3. Geographic Distribution

Country-wise analysis highlights the major regions contributing content to the dataset.

### 4. Content Growth

Release-year analysis provides an overview of how the Netflix content library has evolved over time.

### 5. Ratings

Rating analysis helps understand the audience categories targeted by different types of content.

### 6. Duration

Movie duration analysis provides insights into the typical length of movies available on the platform.

### 7. TV Show Seasons

Season analysis helps understand the structure and longevity of TV shows.

# 💡 Business / Strategic Insights

Although this is an entertainment analytics project, the dashboard demonstrates several important business intelligence concepts.

### Content Strategy

Understanding genres and content types can help streaming platforms evaluate their content portfolio.

### Geographic Strategy

Country-level analysis can help identify strong content-producing regions.

### Audience Analysis

Ratings and genres provide an indication of the different audience categories represented within the content library.

### Content Planning

Release-year trends can help identify changes in content availability and production patterns.

### Portfolio Analysis

Comparing Movies, TV Shows, genres, ratings, and countries provides a broader view of the platform's content portfolio.
