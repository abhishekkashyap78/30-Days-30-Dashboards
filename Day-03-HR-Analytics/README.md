👩‍💼 HR Analytics Dashboard – Power BI Project
📊 Project Overview

This project analyzes employee data using Power BI to uncover insights about workforce trends, performance, and attrition.
The dashboard helps HR teams make data-driven decisions about hiring, retention, and diversity.

🎯 Objectives

To monitor key HR metrics such as attrition, hiring trends, and employee performance.

To identify factors influencing employee turnover.

To visualize workforce diversity, satisfaction, and department-wise headcount.

📁 Dataset

Source: IBM HR Analytics Dataset (Kaggle)

File used: HR_Employee_Attrition.csv

Main fields:

Employee ID

Age, Gender, Department, Job Role

Salary, Experience, Education

Performance Rating, Attrition, Tenure

🧹 Data Preparation

Cleaned missing and duplicate data in Power Query.

Added calculated columns using DAX:

Attrition Rate (%)

Average Salary by Department

Employee Satisfaction Index

Created measures for KPIs like Total Employees, Active Employees, Attrition Count.

📈 Dashboard Features

Overview Page – Key HR KPIs (total employees, attrition rate, avg. salary).

Attrition Analysis – Breakdown by age, gender, department, and job role.

Employee Performance – Ratings vs salary and experience.

Diversity Analysis – Gender and department-wise headcount.

🛠️ Tools & Technologies

Power BI Desktop – Dashboard creation

Power Query – Data cleaning and transformation

DAX – Calculations and KPIs

Excel / CSV – Dataset source

💡 Key Insights

Higher attrition observed in young employees with low experience.

R&D and Sales departments show highest turnover rates.

Employees with higher satisfaction and training have better retention.
