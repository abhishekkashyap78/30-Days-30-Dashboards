## 📌 Project Overview

This project is **Day 14 of my 30 Days, 30 Dashboards Challenge**.

For Day 14, I created an interactive **Healthcare Analytics Dashboard using Microsoft Power BI**.

The purpose of this dashboard is to transform healthcare data into meaningful and easy-to-understand insights.

Healthcare organizations generate large amounts of data related to patients, medical conditions, hospitals, treatments, demographics, and healthcare operations. An interactive dashboard can help stakeholders explore this information and identify important patterns.

This project focuses on using **Data Analytics, Power BI, Power Query, DAX, and Data Visualization** to build a healthcare-focused business intelligence solution.

---

# 🎯 Project Objectives

The main objectives of this project were:

- Analyze healthcare and patient data.
- Understand patient demographics.
- Analyze medical conditions.
- Identify important healthcare trends.
- Monitor key performance indicators.
- Compare different categories of healthcare data.
- Create an interactive reporting system.
- Convert raw healthcare data into meaningful insights.
- Demonstrate the application of Power BI in healthcare analytics.

---

# 🏥 Business Problem

Healthcare organizations need to analyze large amounts of patient and operational data to improve decision-making.

Traditional spreadsheets and static reports can make it difficult to quickly answer questions such as:

- How many patients are being analyzed?
- What are the major patient demographics?
- Which medical conditions are most common?
- How is patient data distributed across different categories?
- What trends can be identified from the available healthcare data?
- Which areas require more attention?
- How can healthcare data be monitored through a centralized dashboard?

The goal of this project is to provide an interactive solution for exploring these questions.

# 🧹 Data Preparation

Before building the dashboard, the healthcare dataset was prepared for analysis.

The data preparation workflow included:

1. Importing the healthcare dataset.
2. Reviewing the available columns.
3. Checking data types.
4. Identifying missing values.
5. Removing unnecessary columns.
6. Cleaning categorical fields.
7. Standardizing values.
8. Transforming the dataset using Power Query.
9. Creating calculated measures using DAX.
10. Loading the prepared data into Power BI.
