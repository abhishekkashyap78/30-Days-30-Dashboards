# Day 10 - COVID-19 Analytics Dashboard

## 📊 Overview
An interactive Power BI dashboard designed to analyze the global impact
and progression of COVID-19 through cases, deaths, recoveries, and trends.

## 🎯 Business Problem
COVID-19 generated large amounts of data across countries and regions.
The objective was to transform this data into meaningful visual insights
and understand how the pandemic evolved over time.

## 💡 Key Insights
- Analyzed confirmed COVID-19 cases
- Tracked deaths and recoveries
- Compared countries and regions
- Analyzed case trends over time
- Identified major pandemic trends

## 🚀 Analytical Action
The dashboard helps users compare regions, monitor case trends,
and understand the progression and impact of the pandemic.

## 🛠️ Tools Used
- Power BI
- Power Query
- DAX
- Data Visualization
