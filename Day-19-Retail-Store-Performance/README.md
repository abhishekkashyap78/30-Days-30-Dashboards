## 📊 Project Overview

This project is part of my **30 Days, 30 Dashboards Challenge**.

For Day 19, I created an interactive **Retail Store Performance Dashboard using Microsoft Power BI** to analyze store-wise sales, revenue, product performance, quantity sold, and sales trends.

The dashboard provides a clear overview of retail performance and helps identify high-performing stores, products, and business trends.

---

## 🎯 Business Problem

Retail businesses generate large amounts of sales and product data across multiple stores.

Without proper analysis, it can be difficult to understand:

- Which stores are performing well?
- Which products generate the most sales?
- What are the overall sales trends?
- Which products have higher demand?
- How much quantity is being sold?
- Which stores or products need attention?

This dashboard converts raw retail data into meaningful and interactive insights.

---

## 🚀 Project Objectives

The main objectives of this dashboard are:

- Analyze overall retail sales performance
- Compare store-wise performance
- Analyze product performance
- Identify top-performing products
- Analyze quantity sold
- Track sales trends over time
- Compare product/category performance
- Understand sales contribution
- Identify performance gaps

- Removing duplicate records
- Handling missing values
- Correcting data types
- Standardizing column names
- Cleaning product information
- Formatting date fields
- Creating required calculated columns
- Preparing data for analysis
