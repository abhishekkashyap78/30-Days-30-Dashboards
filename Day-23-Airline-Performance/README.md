## 📊 Project Overview

This project is part of my **30 Days, 30 Dashboards Challenge**.

For Day 23, I created an interactive **Airline Performance Dashboard using Microsoft Power BI** to analyze flights, passengers, revenue, delays, cancellations, routes, and overall airline performance.

The dashboard transforms raw airline data into meaningful business insights that can support better operational planning and decision-making.

---

## 🎯 Business Problem

Airline businesses generate large amounts of data related to:

- Flights
- Passengers
- Routes
- Airports
- Revenue
- Delays
- Cancellations
- Flight status
- Travel dates

Without proper analysis, it can be difficult to understand operational performance, identify delay patterns, compare routes, and analyze passenger demand.

This dashboard provides an interactive solution for analyzing airline performance.

---

## 🚀 Project Objectives

The main objectives of this dashboard are:

- Analyze overall airline performance
- Monitor total flights
- Analyze passenger volume
- Track revenue performance
- Analyze flight delays
- Study cancellation patterns
- Compare airlines
- Compare routes
- Analyze airport performance
- Identify high-performing routes
- Study flight trends over time

## 🧹 Data Cleaning & Transformation

The raw airline dataset was prepared using **Power Query**.

The data preparation process included:

- Removing duplicate records
- Handling missing values
- Correcting data types
- Standardizing airline names
- Cleaning airport information
- Formatting date fields
- Creating calculated columns
- Handling inconsistent values
- Preparing data for analysis
