## 📊 Project Overview

Welcome to **Day 16 of my 30 Days, 30 Dashboards Challenge**!

In this project, I created an interactive **Spotify Music Analytics Dashboard** using Microsoft Power BI.

The dashboard analyzes music-related data to understand patterns in:

- 🎤 Artists
- 🎵 Tracks
- 🎧 Music popularity
- 📈 Streams and performance
- 🎼 Genres
- 📅 Music trends
- 🔊 Audio features
- ⭐ Song and artist performance

The objective of this dashboard is to transform raw Spotify music data into meaningful and interactive visual insights.

---




## 🎯 Business Problem

Music platforms generate large amounts of data related to songs, artists, genres, popularity, streams, and audio characteristics.

The challenge is to convert this raw data into useful information that can help understand:

- Which artists are performing well?
- Which songs are the most popular?
- Which genres dominate the dataset?
- How does song popularity vary?
- Which tracks have higher streaming performance?
- What patterns can be observed in music trends?
- How do different audio features relate to song performance?

This dashboard provides an interactive way to explore these questions.

## 🧹 Data Cleaning & Preparation

Before creating the dashboard, the raw dataset was processed using Power Query.

### Data Preparation Steps

1. Imported the Spotify dataset.
2. Checked column names.
3. Checked data types.
4. Removed unnecessary columns.
5. Handled missing values.
6. Removed duplicate records.
7. Standardized text values.
8. Converted numerical columns into appropriate data types.
9. Checked popularity and streaming values.
10. Prepared the final dataset for visualization.
