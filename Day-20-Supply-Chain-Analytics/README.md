## 📊 Project Overview

This project is part of my **30 Days, 30 Dashboards Challenge**.

For Day 20, I created an interactive **Supply Chain Analytics Dashboard using Microsoft Power BI**.

The dashboard analyzes inventory, suppliers, orders, delivery performance, shipping information, lead times, and supply chain costs to provide meaningful business insights.

---

## 🎯 Business Problem

Supply chain operations generate large amounts of data related to:

- Inventory
- Suppliers
- Orders
- Shipments
- Delivery times
- Product demand
- Logistics costs

Without proper analysis, businesses may face inventory issues, delivery delays, supplier performance problems, and increased operational costs.

This dashboard converts raw supply chain data into interactive visual insights.

---

## 🚀 Project Objectives

The main objectives of this project are:

- Analyze overall supply chain performance
- Monitor inventory levels
- Compare supplier performance
- Analyze order quantities
- Track delivery performance
- Identify delivery delays
- Analyze lead times
- Monitor supply chain costs
- Identify operational trends
- Support data-driven decision-making
