## 📊 Project Overview

This is Day 28 of my **30 Days, 30 Dashboards Challenge**.

In this project, I created an **Education Analytics Dashboard using Power BI** to analyze student enrollment, academic performance, attendance, grades, subjects, and student outcomes.

The objective is to transform raw education data into meaningful insights through interactive dashboards and data visualization.

---

## 🎯 Business Problem

Educational institutions generate large amounts of student data, but raw data alone does not provide actionable insights.

This dashboard helps answer questions such as:

- How many students are enrolled?
- What is the average student performance?
- Which subjects have better performance?
- What is the student pass/fail rate?
- Is attendance related to academic performance?
- Which classes or departments perform better?
- Which student segments need additional attention?

---

## 🎯 Project Objectives

- Analyze student performance
- Track enrollment trends
