## 📊 Project Overview

This project is part of my **30 Days, 30 Dashboards Challenge**.

For Day 21, I created an interactive **Restaurant Performance Dashboard using Microsoft Power BI** to analyze restaurant sales, orders, revenue, menu item performance, customer ratings, and business trends.

The dashboard transforms raw restaurant data into meaningful insights that can support better operational and business decisions.

---

## 🎯 Business Problem

Restaurants generate large amounts of data related to:

- Orders
- Sales
- Revenue
- Menu items
- Customers
- Ratings
- Categories
- Locations

Without proper analysis, it can be difficult to understand customer preferences, identify popular menu items, track sales performance, and find areas that require improvement.

This dashboard provides an interactive view of restaurant performance.

---

## 🚀 Project Objectives

The main objectives of this dashboard are:

- Analyze overall restaurant performance
- Track total sales and revenue
- Analyze order volume
- Identify top-performing menu items
- Compare menu/category performance
- Analyze customer ratings
- Study sales trends
- Understand customer demand
- Identify high and low-performing areas

- Correcting data types

- Cleaning menu item information
- Formatting date fields
- Creating calculated columns
- Transforming data for analysis
